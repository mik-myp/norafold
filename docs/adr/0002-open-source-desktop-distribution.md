# ADR 0002：开源桌面应用分发边界

- 状态：已接受
- 日期：2026-09-02

## 背景

项目面向 GitHub 开源分发，需要提供 macOS 和 Windows 的可安装应用，同时保持发布配置简单，不要求维护者预置平台证书或私有分发服务。

## 决策

- GitHub Release 提供 Electron Forge 生成的 macOS 和 Windows 安装产物。
- 当前不配置 macOS 代码签名、公证或权限定制，也不配置 Windows 代码签名。
- 用户自行判断下载来源、安装风险并决定是否安装；项目不通过脚本绕过系统安全提示。
- 发布流程不额外生成 checksums 或 SBOM，除非未来明确提出供应链交付要求。
- 应用图标暂时使用 Electron 默认资源；正式品牌图标准备完成后再更新 Forge 配置。

## 结果

未签名应用在 macOS 可能触发 Gatekeeper 提示，在 Windows 可能触发 SmartScreen 提示，这是当前公开分发边界的已知限制。后续如需签名、公证、权限或附加供应链产物，应另建 ADR 并同步更新发布工作流和安全文档。
